## 🧠 Selected Projects

### 🚚 [RL-ACA — Reinforcement Learning Assignment Algorithm](https://github.com/TristanKruse/RMDP_Algorithm)

A reinforcement-learning approach to food-delivery logistics, using **Deep Q-Networks** to learn dynamic postponement decisions for order assignment and bundling.

- Evaluated on **647,395 real-world Meituan orders across 22 districts**
- Achieved **5.5% lower average distance per order** and **1.5 pp lower driver idle rates**
- Improved on-time delivery by **4.4 pp in high-stress scenarios**

**Tech:** Python · PyTorch · Deep Q-Networks · NumPy · Pandas

### 🛍️ [OmniChannel-RL](https://github.com/TristanKruse/Modelling_returns_omni-channel_retail_Reinforcement_Learning)

A reinforcement-learning framework for inventory and allocation decisions in omnichannel retail with resellable returns.

- Combines a **Hierarchical Markov Decision Process (HMDP)** with **Proximal Policy Optimization (PPO)**
- Achieved a **3% reduction in total costs** and up to a **17% increase in service levels**

**Tech:** Python · TensorFlow · Keras · PPO · Gym

### 🍺 [Beer-Game-RL](https://github.com/TristanKruse/Beer-Game-RL)

A reinforcement-learning implementation of the classic **Supply Chain Beer Game**, exploring automated ordering policies under supply-chain uncertainty.

- Applied **Q-Learning** to optimize replenishment decisions
- Achieved a **31% reduction in total costs** through an improved state-space representation

**Tech:** Python · NumPy · Pandas · Q-Learning
